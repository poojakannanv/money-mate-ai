# MoneyMate AI: Full Project Roadmap

**An AI personal finance co-pilot for UK households.**

Upload a bank statement, get instant AI-powered categorisation, ask your finances anything in plain English, and receive weekly budget coaching. Built to take on the UK cost-of-living crisis with a conversational AI agent that actually understands your money.

## The Problem

UK households are squeezed. Energy bills, groceries, rent, and council tax have all climbed sharply, and most personal finance apps still expect users to do the hard work themselves: manually categorise transactions, set rigid budgets, and decode their own spending patterns. The result is that the people who most need clarity over their money are the least likely to get it.

Existing apps fall into two camps:
1. **Manual budgeting tools** (YNAB, Money Dashboard) that demand discipline most people do not have spare.
2. **Bank-native insights** (Monzo, Starling) that are locked into one bank and rarely give actionable advice.

**Neither talks to you like a human financial advisor would.** That is the gap MoneyMate AI fills.

## The Solution

A conversational AI co-pilot that:
- Reads any UK bank's CSV statement
- Auto-categorises every transaction with explanations
- Lets you ask anything in plain English ("How much did I spend on takeaways last month?" "What is my biggest avoidable expense?")
- Sends a weekly insights digest with concrete actions
- Suggests which utility bills to switch and roughly how much you could save

All of this runs on a single LLM-powered backend with function calling, so the AI does not hallucinate numbers, it queries your actual data.

## Core Features (v1.0)

1. **Secure account and CSV upload** with support for major UK banks (HSBC, Barclays, Lloyds, NatWest, Monzo, Starling, Revolut CSV formats)
2. **AI transaction categorisation** with categories tuned for UK life (Council Tax, NHS Prescriptions, TV Licence, Tube and Rail, Pub and Restaurants, etc.)
3. **Conversational chat** powered by Claude or GPT with function calling against your transaction database
4. **Spending dashboard** with monthly trends, category breakdowns, and unusual-spend flags
5. **Weekly digest** generated by AI, surfacing patterns and actions
6. **Privacy-first design** with all data stored under your account, no third-party sharing

## Tech Stack

| Hosting | Vercel (frontend and edge functions) + Supabase | Free tier sufficient for portfolio |

## AI Architecture

The AI is not a chat layer bolted onto a finance app. It is the centre of the product:

```
User uploads CSV
      v
Transaction parser (Papaparse + bank-format detectors)
      v
AI Categoriser (Claude batch call, structured JSON output, validates against category enum)
      v
Postgres: transactions table with category, confidence, raw_text
      v
User opens chat
      v
Vercel AI SDK streams responses, with function-calling tools:
      - getTransactions(filters)
      - getCategorySummary(month)
      - findRecurringPayments()
      - compareToPrevious(period)
      v
AI answers grounded in real data, never invented numbers
      v
Weekly digest cron generates personalised insights
```

## Public Data Sources

MoneyMate uses only public and user-provided sources, never employer-confidential data:
- User uploads (their own statements)
- ONS Consumer Price Index for context (free public API)
- UK gov.uk benefits data for reference (Universal Credit, council tax bands)
- Energy price cap data (Ofgem, public)
- Comparison benchmarks via public datasets

## Future Scope (where this becomes a real product)

The v1.0 build is a portfolio proof. The genuinely interesting future is the agentic layer:

1. **Open Banking integration** via TrueLayer or Plaid UK, so no CSV uploads needed.
2. **Autonomous bill negotiation agent** that drafts switch requests, fills supplier forms, schedules calls.
3. **Predictive cash flow** that warns "you will overdraw on 23 March based on your patterns".
4. **Household sharing** with role-based access for couples and families.
5. **Voice mode** with Whisper or Realtime API for hands-free check-ins on the commute.
6. **Goals and savings agent** that auto-moves money to savings pots when you stay under budget.
7. **Tax and self-assessment helper** for the 4.3 million UK self-employed.
8. **Financial wellbeing scoring** integrated with credit-improvement nudges.

This trajectory tracks exactly where consumer fintech is heading in 2026 and beyond, and is the strongest possible interview talking point for fintech, AI-engineering, or full-stack roles in the UK.

## Weekend 2: Data In and AI Categorisation (23 to 24 May 2026)

### Day 3, Saturday 23 May: CSV Upload Pipeline
- Build `/upload` page with drag-and-drop file area
- Install Papaparse, build a CSV parser that handles at least three UK bank formats: Monzo, Starling, and a generic format (date, description, amount, balance)
- Show a parsed preview table before commit
- Build server action to write transactions to Postgres, with `userId` foreign key
- Handle duplicate-detection (hash of date + description + amount)
- **Deliverable:** Upload a CSV, see it parsed, confirm it is saved in Supabase. Tag: `v0.2-upload`.

### Day 4, Sunday 24 May: AI Categorisation Engine
- Sign up for Anthropic API, add `ANTHROPIC_API_KEY` to Vercel env
- Install `@anthropic-ai/sdk` and `ai` (Vercel AI SDK)
- Define UK-tuned category enum: Groceries, Eating Out, Transport (Tube and Rail), Transport (Car and Fuel), Utilities (Energy), Utilities (Water), Council Tax, Internet and Mobile, Rent and Mortgage, Subscriptions, Health and Pharmacy, Shopping, Entertainment, Income, Savings and Investments, Transfers, Other
- Build `categoriseTransactions(batch)` that sends 20 transactions at a time, asks Claude for structured JSON: `[{id, category, confidence, reasoning}]`
- Validate response against the enum, retry once on parse failure
- Save category and confidence back to each transaction
- Build a "Re-categorise all" button on the dashboard
- **Deliverable:** Upload a statement, every transaction comes back categorised with a confidence score. Tag: `v0.3-ai-categorise`.

## Weekend 4: Function Calling and Ship (6 to 7 June 2026)

### Day 7, Saturday 6 June: Function Calling Against Real Data
- Define tools for Claude using the AI SDK `tool()` helper:
  - `getCategorySummary({month, year})` returns total per category for that month
  - `getTransactions({category?, dateFrom?, dateTo?, limit})` returns matching transactions
  - `findRecurringPayments()` returns subscriptions by detecting same-amount-same-day-each-month patterns
  - `compareSpending({periodA, periodB})` returns deltas
- Wire these tools into the chat route, scoped to the logged-in user only (never let the AI access another user's data)
- Test queries: "How much did I spend on takeaways last month?", "What are my recurring subscriptions?", "Show me unusual spending in May", "Compare this month to last month"
- **Deliverable:** A working AI agent that answers questions grounded in your actual transactions. Tag: `v0.6-function-calling`.

### Day 8, Sunday 7 June: Weekly Insights, Polish, Launch

- Pass through every page on mobile, fix responsive issues
- Add a global loading skeleton, error boundary, and friendly empty states
- Add a footer with: "Built by Pooja Kannan as a UK web developer portfolio project. Source on GitHub."
- Record a 60 to 90 second demo video, upload unlisted on YouTube
- Push final tag `v1.0`
- Write a LinkedIn post: "Built MoneyMate AI in 8 weekends. Here is what shipping a conversational AI app on Next.js taught me about prompt engineering, function calling, and UK consumer finance."
